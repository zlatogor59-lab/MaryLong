# Модуль марганца

Статус: реализовано и проверено 2026-09-27.

Марганец включён в общий версионируемый `mineral_profile` продукта и рассчитывается в миллиграммах через существующий пищевой минеральный калькулятор. Следовые значения сохраняются отдельно, а отсутствующие данные не заменяются нулём. Сравнение с ориентиром доступно только при достаточном покрытии строк и массы.

Для клиента добавлен отдельный сохраняемый ориентир `manganese_target_mg`. Марганец участвует в минеральной карте, ранжировании надёжных сигналов и общем клиентском объяснении. Изменение ориентира или рациона делает прежнее одобрение минерального текста неактуальным.

Источник контрольного набора — CoFID 2021, лист `1.4 Inorganics`, столбец `Manganese (mg)`. В PHOTO-001 значение доступно для 18 из 19 продуктов. Контрольный итог — 1,373 мг, покрытие массы — около 97,7%; результат помечается как нижняя оценка из-за одной строки без значения.

Миграция: `202609270001_manganese_target`. Она применена к локальной PostgreSQL, а 19 профилей PHOTO-001 синхронизированы. Повторный сухой запуск не планирует изменений.

Автоматические проверки: 524 теста без ошибок, из них 5 тестов БД пропущены настройкой набора; сборка и синтаксическая проверка браузерного JavaScript успешны.
