# Модуль молибдена

Статус: безопасное основание реализовано 2026-09-27; количественный вывод для PHOTO-001 заблокирован недостаточным покрытием.

Молибден включён в общий `mineral_profile`, пищевой минеральный калькулятор, индивидуальные ориентиры, минеральную карту и общий клиентский текст. Единица расчёта — микрограммы. Отсутствующие значения не заменяются нулём, а клиентское объяснение не делает вывода о поступлении, пока шлюз полноты не пройден.

CoFID 2021 и USDA SR Legacy не предоставляют пригодных значений молибдена для продуктов PHOTO-001. В USDA FoodData Central Foundation 2026-04 найдено аналитическое среднее для сырого огурца с кожурой: 3,723 мкг/100 г, запись FDC 2346406. Значение подключено к точной карточке огурца как межбазовый источник со статусом `borrowed`; для остальных карточек явно сохранён статус `missing`.

В контрольном рационе известная сумма составляет 1,862 мкг, но покрытие массы ниже 3%. Поэтому статус — `insufficient_data`, доля ориентира не рассчитывается, сигнал не ранжируется и клиенту не публикуется как низкое поступление.

Миграция `202609270002_molybdenum_target` добавляет `molybdenum_target_ug`; она применена к локальной PostgreSQL. Профили 19 продуктов синхронизированы, повторный сухой запуск не планирует изменений.

Проверки: 528 тестов пройдено, 5 тестов БД пропущены настройкой набора; сборка и синтаксическая проверка браузерного JavaScript успешны.
