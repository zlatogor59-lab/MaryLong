# Клиентская публикация витамина D

Статус: реализовано и проверено 2026-09-27.

Сервер формирует нейтральный клиентский черновик по пищевому поступлению витамина D. При недостаточной полноте данных сравнение с рабочим ориентиром не публикуется как достоверное. Текст не оценивает обеспеченность организма, не устанавливает дефицит и не содержит назначения, дозировки или рекомендации продукта.

Консультант отдельно одобряет текущую версию через `PATCH /clients/:clientId/submissions/:submissionId/vitamins/vitamin-d/client-explanation/approve`. Одобрение привязано к версии сохранённого рациона и хешу текста; изменение исходного рациона или текста делает прежнее одобрение неактуальным.

После одобрения раздел `vitamin_d` включается в общую клиентскую нутритивную сводку. В интерфейсе рядом с расчётом витамина D доступны превью текста, статус публикации и отдельная кнопка одобрения.

Проверки: полный набор без БД — 521 тест пройден, 5 тестов БД пропущены; сборка и синтаксическая проверка браузерного JavaScript успешны. Текущая среда использует Node.js 24 вместо заявленного Node.js 22, поэтому пакетный менеджер выводит предупреждение о версии движка.
